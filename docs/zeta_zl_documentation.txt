============================================================
1.  ARCHITECTURE OVERVIEW
============================================================

  zeta.zl is a full language extension on top of ZPP (the
  ZETA++ base interpreter). ZPP only understands standard
  identifiers, literals, and basic control flow. zeta.zl
  adds special syntax that ZPP cannot parse on its own:

    Operators added by zeta.zl:
      @   — directive prefix
      #   — (inherited from ZPP interpolation)
      %   — register dereference sigil
      ^   — (reserved)
      ->  — result-binding / return arrow
      :   — slot separator / body-open prefix
      :-> — body-open arrow
      $   — allocation sigil
      $-> — register-write arrow

  To keep ZPP safe, ALL such syntax is intercepted by the
  ZetaSafeLayer before ZPP's parser ever sees it.

  Subsystems
  ──────────
    ZetaRegisterFile      8 registers × 4 typed slots
    ZetaMemoryManager     Allocation ledger with free()
    ZetaTagEngine         40+ execution-modifier <tags>
    ZetaDirectiveEngine   18 @-directives
    ZetaPortionRegistry   portion / section namespace tree
    ZetaGUI               Electron + Canvas rendering
    ZetaEngine3D          Scene graph + mesh + physics
    ZetaModuleLoader      .zl library integration


============================================================
2.  EXECUTION PIPELINE
============================================================

  .zl source file
      │
  ZetaSafeLayer ─── rewrites special syntax to placeholders
      │               BEFORE ZPP's parser sees raw chars
      │
  ZetaLexer ──────── tokenises all zeta.zl special syntax
      │
  ZetaParser ─────── builds ZetaAST (recursive descent)
      │
  ZetaIRCompiler ─── emits ZPP-safe __zeta_* call IR
      │
  ZPP Runtime ────── sees ONLY safe function calls
      │
  ZetaExecutor ───── resolves tags, directives, side-effects

  IMPORTANT: Arithmetic operators (+, -, *, /, =, >, <) are
  never emitted raw into ZPP IR. They are compiled to
  __zl_calc__(a, "op", b) calls.

4.  ZETA.ZL SYNTAX — NEW CONSTRUCTS BEYOND ZPP
============================================================

  4.1  medium_zeta Block
  ──────────────────────
  The top-level namespace declaration. Must be opened with
  the :-> body-arrow and closed with -> result(...).

    medium_zeta :-> {
        @directive          // optional block-level directives
        portion .name
            section <func>.myFunc -> num, str :->
                ...
    } -> result([myFunc]);

  4.2  portion
  ────────────
  A named namespace grouping sections (functions/structs).

    portion .myPortion
        section <func>.doThing :->
            ...

  4.3  section
  ────────────
  Declares a function or struct inside a portion.

    section <func>.name -> paramType, paramType :->
        // body

    section <struct>.name -> field1Type, field2Type :->
        // (struct factory, no body required)

  4.4  Register Syntax
  ────────────────────
  Registers: r1 .. r8 (8 total)
  Slots per register: :0 .. :3 (4 total)

    r1 $-> <type>:value, <type>:value;    // write register
    %r1                                    // read all slots
    %r1:0                                  // read slot 0
    free r1, r2;                           // zero registers

  4.5  Function Call Syntax
  ─────────────────────────
    .portion --->funcName --> arg1, arg2 -> <tag><$rN>;
    //         ^^^^^^^^^^^    ^^^^^^^^^     ^^^^^^^^^^
    //         call-open      arg-sep       result tag
    //         (---> )        (-->)         bound to register

  4.6  result() Declaration
  ─────────────────────────
  Closes the medium_zeta block and exports named symbols.

    -> result([func1, func2], [Struct1]);

  4.7  Arrow Tokens Summary
  ─────────────────────────
    --->   ARROW_TRIPLE   open a function call
    -->    ARROW_DOUBLE   separate arguments
    ->     ARROW_SINGLE   result-binding / return
    :->    COLON_ARROW    open a body (section/medium_zeta)
    $->    DOLLAR_ARROW   write to a register

5.  TOKEN TAXONOMY
============================================================

  The ZetaLexer produces the following token types:

  Structure Tokens
    MEDIUM_ZETA, LBRACE, RBRACE, NEWLINE, INDENT, DEDENT
    COMMA, SEMICOLON, DOT, COLON

  Arrow Family
    ARROW_TRIPLE (---)    call-open
    ARROW_DOUBLE (-->)    arg-separator
    ARROW_SINGLE (->)     result-binding / return
    COLON_ARROW  (:->)    body-open
    DOLLAR_ARROW ($->)    register-write

  Memory / Register
    DOLLAR      ($)       allocate sigil
    PERCENT     (%)       read sigil (standalone)
    REGISTER    (r1..r8)  bare register reference
    REG_SLOT    (r1:0)    bare slot-ref expression
    REG_DEREF   (%r1, %r1:0)  dereferenced register value
    FREE                  free keyword

  Declaration Keywords
    PORTION, SECTION, RESULT

  Type Keywords
    TYPE_NUM, TYPE_STR, TYPE_BOOL, TYPE_LET, TYPE_ARRAY

  Section-Kind Keywords
    SECT_FUNC, SECT_STRUCT

  Tags and Directives
    TAG        (<name> or <name><$rX[:slot]>)
    DIRECTIVE  (@name)

  Literals
    NUMBER_LIT, STRING_LIT, BOOL_LIT

  General
    IDENTIFIER, EOF

6.  ZETALEXER
============================================================

  Class: ZetaLexer

  Constructor
    new ZetaLexer(src: string)
      Constructs a lexer for the given source string.

  Methods
    .tokenize() → Token[]
      Runs the full tokenisation pass and returns an array
      of token objects.

  Each token object has the shape:
    { type: string, val: any, line: number, col: number }

  Internal helpers (not public API):
    _ch(off?)   peek at character at offset
    _adv()      advance one character
    _match(s)   try to consume a literal string
    _tok(...)   construct a token object
    _skipLineComment()
    _readStr()
    _readNum()
    _readIdent()
    _emitIndent(spaces)

  The lexer handles indent-based block structure via an
  internal indent-level stack (_iStack) and a
  beginning-of-line flag (_bol).

8.  ZETAREGISTERFILE
============================================================

  Class: ZetaRegisterFile

  Provides 8 registers (r1..r8), each with 4 typed slots
  (0..3). Slot objects have the shape { type, value }.

  Constructor
    new ZetaRegisterFile()

  Methods
    .write(r, assignments)
      Write consecutive slots of register r from an array of
      assignment objects: { typeTok, value }.
      Throws if register is locked or out of range.

    .writeSlot(r, slot, type, value)
      Write a single slot with a specific type and value.

    .read(r) → slot[]
      Read all 4 slot objects of register r.

    .readSlot(r, slot) → { type, value }
      Read one specific slot object.

    .readValue(r, slot?) → any
      If slot is given, returns that slot's .value.
      If slot is null, returns the single non-null value if
      only one slot is set, or a 4-element array otherwise.

    .free(...regs)
      Zero out all slots of the specified registers and
      remove any locks on them.

    .lock(r)
      Lock a register to prevent writes (used during 3D/
      physics operations).

    .unlock(r)
      Remove a lock from a register.

    .dump() → object
      Returns a human-readable object mapping r1..r8 to
      formatted slot descriptions. Useful for debugging.

  Validation
    _validateReg(r)   — throws ZetaError if r < 1 or r > 8
    _validateSlot(s)  — throws ZetaError if s < 0 or s > 3

  Register access syntax (in .zl source):
    r1 $-> <num>:42;          // write 42 to r1 slot 0
    %r1                        // read all slots of r1
    %r1:0                      // read slot 0 of r1
    free r1;                   // zero r1


============================================================
9.  ZETAMEMORYMANAGER
============================================================

  Class: ZetaMemoryManager

  A simple allocation ledger. Addresses are integers starting
  at 0x1000. Each cell stores: { size, type, data, freed }.

  Constructor
    new ZetaMemoryManager()

  Methods
    .alloc(type, data) → address (number)
      Allocates a new cell and returns its address.
      Increments internal stats.

    .read(addr) → data
      Reads the data stored at address.
      Throws ZetaError on invalid address or use-after-free.

    .write(addr, data)
      Overwrites the data at address.
      Throws ZetaError if address is invalid or freed.

    .free(addr)
      Marks a cell as freed (does not erase data).

    .freeAll()
      Marks every allocated cell as freed.

    .stats() → object
      Returns { allocs, frees, bytesAllocated, liveObjects }.

  Internal
    ._sizeof(type, data) → number (bytes)
      num  = 8 bytes
      bool = 1 byte
      str  = length × 2 bytes
      array= length × 8 bytes
      let/other = 64 bytes (default)

  Size accounting is approximate (for diagnostic purposes).

10. ZETATAGENGINE — BUILT-IN TAGS
============================================================

  Class: ZetaTagEngine

  Tags are execution-modifier functions applied via <tagName>
  syntax. They are NOT syntax keywords — they are dispatched
  at runtime by a handler Map.

  Constructor
    new ZetaTagEngine(runtime: ZetaRuntime)

  Methods
    .register(name, fn)
      Register a new tag handler at runtime.
      fn receives (ctx, runtime) and returns a value.

    .execute(tagName, ctx) → any
      Dispatch a tag by name with a context object.
      Throws ZetaError if the tag name is unrecognised.

  ─────────────────────────────────────────────────────────
  BUILT-IN TAG REFERENCE
  ─────────────────────────────────────────────────────────

  <getVal>
    Extracts ctx.value (or the entire ctx if .value is
    undefined). Used to capture call results into registers.

  <cast>
    Type-cast ctx.value to ctx.targetType.
    Supported target types: 'num', 'str', 'bool', 'array'.

  <calc>
    Safe sandboxed arithmetic. ctx must include:
      op  — one of the operations below
      a   — left operand
      b   — right operand (where applicable)
    Operations:
      add    a + b
      sub    a - b
      mul    a * b
      div    a / b  (returns Infinity on divide-by-zero)
      mod    a % b
      pow    a ^ b
      neg    -a
      abs    |a|
      sqrt   √a
      floor  ⌊a⌋
      ceil   ⌈a⌉
      round  round(a)
      min    min(a, b)
      max    max(a, b)
      clamp  clamp(a, b, c)   (value, lo, hi)
      lerp   lerp(a, b, t)    (start, end, factor)

  <cmp>
    Comparison operations. Returns boolean.
    ctx: { op, a, b }
    Operations: eq, neq, lt, lte, gt, gte

  <logic>
    Boolean operations. Returns boolean.
    ctx: { op, a, b }
    Operations: and, or, not, xor

  <bit>
    Bitwise operations.
    ctx: { op, a, b }
    Operations: and (&), or (|), xor (^), not (~),
                shl (<<), shr (>>), ushr (>>>)

  <mem>
    Memory operations (delegates to ZetaMemoryManager).
    ctx: { op, ... }
    Operations:
      alloc   ctx.type, ctx.data  → address
      read    ctx.addr            → data
      write   ctx.addr, ctx.data  → address
      free    ctx.addr            → null
      stats                       → stats object

  <flow>
    Control flow modifier.
    ctx: { op, condition, then, else, action }
    Operations:
      if      return ctx.then if condition, else ctx.else
      unless  return ctx.then if !condition, else ctx.else
      when    call ctx.action() if condition (side-effect)

  <loop>
    Numeric loop helper. Returns array of body results.
    ctx: { from, to, step, body (function) }
    Iterates from `from` to `to` with step (default 1).

  <iter>
    Array iteration helper.
    ctx: { items (array), body (function) }
    Maps body over each item. Returns result array.

  <io>
    Terminal / stream I/O.
    ctx: { op, data }
    Operations:
      print / write  — write to stdout (no newline)
      println        — write with newline (console.log)
      read           — synchronous stdin read (Node only)

  <render>
    Signal the GUI system to render.
    ctx: { target, data }
    If a GUI is active, calls gui.render(target, data).
    Otherwise passes ctx.data through unchanged.

  <event>
    Event system bridge (delegates to ZetaEventBus).
    ctx: { op, name, data, handler }
    Operations: emit, on, off, once

  <async>
    Asynchronous scheduling.
    ctx: { op, fn, args, ms, promises }
    Operations:
      spawn  — resolve then call fn(args)
      delay  — call fn() after ctx.ms milliseconds
      all    — Promise.all(ctx.promises)
      race   — Promise.race(ctx.promises)

  <err>
    Error creation and throwing.
    ctx: { op, message }
    Operations:
      throw  — throw a new ZetaError(message)
      make   — return a new ZetaError(message)

  <fmt>
    String formatting.
    ctx: { op, value, template?, vars?, width?, fill?,
           len?, indent? }
    Operations:
      template   — fill {key} placeholders from ctx.vars
      pad        — padStart to ctx.width with ctx.fill
      trunc      — slice to ctx.len
      upper      — toUpperCase
      lower      — toLowerCase
      json       — JSON.stringify with optional ctx.indent

  <shape>
    GUI shape descriptor factory. Returns a shape object
    consumed by ZetaGUI._drawShape().
    ctx: { kind, x, y, w, h, fill, stroke, strokeWidth,
           opacity, radius, points, path, clip }
    kind options: 'rect', 'circle', 'ellipse', 'polygon',
                  'path', 'text', 'line'
    Returns: { _zetaShape: true, kind, x, y, width,
               height, fill, stroke, strokeWidth, opacity,
               radius, points, path, clip }

  <mesh>
    3D mesh descriptor factory.
    ctx: { name, vertices, faces, normals, uvs, material }
    Returns: { _zetaMesh: true, name, vertices, faces,
               normals, uvs, material }

  <physics>
    Physics body descriptor factory.
    ctx: { shape, mass, restitution, friction, kinematic,
           pos, vel, angVel }
    shape options: 'box', 'sphere', 'capsule', 'mesh'
    Returns: { _zetaPhysics: true, shape, mass,
               restitution, friction, kinematic,
               position, velocity, angularVel }

  <shader>
    GLSL shader program descriptor.
    ctx: { vert, frag, uniforms, attributes }
    If vert/frag are omitted, the engine's built-in default
    vertex/fragment shaders are used.
    Returns: { _zetaShader: true, vertexSrc, fragmentSrc,
               uniforms, attributes }

  <input>
    Input system bridge (delegates to ZetaInputManager).
    ctx: { op, key, action, fn }
    Operations:
      isDown  — returns bool for ctx.key
      mouse   — returns current mouse state object
      bind    — bind key/action to a function
    Default: returns full input state object.

  <debug>
    Debug and diagnostic operations.
    ctx: { op, label, value, condition, message }
    Operations:
      dump      — console.log label + value
      regDump   — console.table of all registers
      memStats  — console.log memory stats
      assert    — throw ZetaError if !condition
      trace     — console.trace with label

  <type>
    Type introspection on ctx.value.
    Returns: 'num', 'str', 'bool', 'array', or 'let'.

  <arr>
    Array operations (immutable — returns new arrays).
    ctx: { op, arr, val, idx, fn, from, to, other, init,
           sep, depth }
    Operations:
      push     → [...arr, val]
      pop      → arr[0..-1]
      head     → arr[0]
      tail     → arr[1..]
      len      → arr.length
      get      → arr[idx]
      set      → copy with arr[idx] = val
      map      → arr.map(fn)
      filter   → arr.filter(fn)
      reduce   → arr.reduce(fn, init)
      concat   → arr.concat(other)
      slice    → arr.slice(from, to)
      sort     → sorted copy
      reverse  → reversed copy
      flat     → arr.flat(depth)
      uniq     → [...new Set(arr)]
      find     → arr.find(fn)
      includes → arr.includes(val)

  <str>
    String operations.
    ctx: { op, val, sep, arr, sub, from, to, width, fill,
           n, idx }
    Operations:
      len        → s.length
      upper      → s.toUpperCase()
      lower      → s.toLowerCase()
      trim       → s.trim()
      split      → s.split(sep)
      join       → (arr).join(sep)
      includes   → s.includes(sub)
      startsWith → s.startsWith(sub)
      endsWith   → s.endsWith(sub)
      replace    → s.replace(from, to)
      replaceAll → s.replaceAll(from, to)
      slice      → s.slice(from, to)
      pad        → s.padStart(width, fill)
      repeat     → s.repeat(n)
      charCode   → s.charCodeAt(idx)

  <hash>
    FNV-1a 32-bit hash of ctx.value (as string).
    Returns a hex string like '0xA1B2C3D4'.
    Pure JS — no native dependencies.

  <rand>
    Random value utilities.
    ctx: { op, min, max, arr }
    Operations:
      float   → Math.random()          [0,1)
      int     → random integer [min, max]
      bool    → random boolean
      pick    → random element from arr
      shuffle → Fisher-Yates shuffled copy of arr

  <time>
    Timing utilities.
    ctx: { op, start }
    Operations:
      now   → Date.now() (ms timestamp)
      iso   → new Date().toISOString()
      delta → Date.now() - ctx.start
      perf  → performance.now() if available, else Date.now()

  <pipe>
    Functional pipeline.
    ctx: { value, fns (array of functions) }
    Passes ctx.value through each function in order.

  <scope>
    Isolated scope snapshot.
    ctx: { fn?, value }
    Calls ctx.fn() if it is a function, else returns
    ctx.value. (Registers are not restored — scope only
    takes a snapshot for diagnostic purposes.)

  <anim>
    Animation frame helper (browser only).
    ctx: { op, fn, id }
    Operations:
      start → requestAnimationFrame(fn), returns frame ID
      stop  → cancelAnimationFrame(id)

  <json>
    JSON operations.
    ctx: { op, value, indent }
    Operations:
      parse      → JSON.parse(value)
      stringify  → JSON.stringify(value, null, indent)
      clone      → deep clone via JSON round-trip

  <sys>
    System information.
    ctx: { op, key }
    Operations:
      platform → process.platform or 'browser'
      version  → ZL_VERSION constant
      env      → process.env[key]
      argv     → process.argv

  <net>
    HTTP fetch helper (async).
    ctx: { op, url, method, headers, body, json }
    Operations:
      fetch → fetch(url, opts) → Promise<text or JSON>

  <buf>
    Binary buffer operations (Node.js only).
    ctx: { op, size, data, enc, buf }
    Operations:
      alloc → Buffer.alloc(size)
      from  → Buffer.from(data, enc)
      toHex → buf.toString('hex')
      toB64 → buf.toString('base64')

  <particle>
    Particle system descriptor factory.
    ctx: { count, lifetime, emitRate, pos, vel, spread,
           color, size, gravity, texture, blendMode }
    Returns: { _zetaParticle: true, count, lifetime,
               emitRate, position, velocity, spread,
               color, size, gravity, texture, blendMode }
    Defaults:
      count=100, lifetime=2.0, emitRate=10
      gravity=-9.8, blendMode='additive'

  ─────────────────────────────────────────────────────────
  FULL LIST OF VALID TAG NAMES

11. ZETADIRECTIVEENGINE — @-DIRECTIVES
============================================================

  Class: ZetaDirectiveEngine

  Directives are activated with the @name syntax. They can
  prefix a single statement or appear inside a medium_zeta
  block to activate for the entire block.

  Constructor
    new ZetaDirectiveEngine(runtime: ZetaRuntime)

  Methods
    .activate(name)    — add directive to active set
    .deactivate(name)  — remove from active set
    .isActive(name)    — check if directive is active
    .handle(name, payload) → any
      Dispatch a directive handler with a payload object.
      Throws ZetaError if name is unknown.

  ─────────────────────────────────────────────────────────
  BUILT-IN DIRECTIVE REFERENCE
  ─────────────────────────────────────────────────────────

  @glb
    Promotes a value to the global scope.
    payload: { name, value }
    Usage: makes a portion's symbol accessible globally.

  @term
    Terminal / console operations.
    payload: { op, data?, title? }
    Operations:
      write      — write data to terminal
      clear      — clear terminal screen
      setTitle   — set terminal window title

  @gui
    Bootstrap and control the GUI subsystem (ZetaGUI).
    Lazily creates the GUI instance if not yet active.
    payload: { op, ... }
    Operations:
      createWindow  — create a new window (see §14)
      show          — show a window
      hide          — hide a window
    Returns the ZetaGUI instance.

  @engine
    Bootstrap and control the 3D engine (ZetaEngine3D).
    Lazily creates the engine if not yet active.
    payload: { op, name?, scene?, mesh?, light?,
               camera?, dt? }
    Operations:
      newScene   — create a new scene by name
      addMesh    — add a mesh descriptor to a scene
      addLight   — add a light to a scene
      setCamera  — configure the scene camera
      step       — advance physics by dt seconds
      render     — render a scene to a target

  @mem
    Memory manager access.
    payload: { op, type?, data?, addr? }
    Operations:
      alloc   — allocate data of type
      free    — free an address
      stats   — return memory statistics
      freeAll — mark all allocations as freed
    No payload: returns stats object.

  @sys
    System-level hooks.
    payload: { op, code? }
    Operations:
      exit  — process.exit(code) on Node
      info  — return { version, platform }
      gc    — trigger full memory freeAll

  @async
    Asynchronous context.
    payload: { op, fn }
    Operations:
      run — execute fn() in an async IIFE

  @import
    Module import.
    payload: { name }
    Calls ZetaModuleLoader.load(name) and returns the module.

  @export
    Symbol export.
    payload: { name, value }
    Writes the value into runtime.exports under name.

  @debug
    Toggle debug mode.
    payload: { on? } (default: true)
    When on, the runtime logs tokens, AST, and IR to console.

  @net
    Network operations.
    Delegates to the <net> tag handler.
    payload: same as <net> tag context.

  @fs
    File system access (Node / Electron only).
    payload: { op, path?, data? }
    Operations:
      read    — readFileSync(path, 'utf8')
      write   — writeFileSync(path, data)
      exists  — existsSync(path)
      ls      — readdirSync(path)

  @crypto
    Cryptographic helpers (Node only, uses 'crypto' module).
    payload: { op, data?, n? }
    Operations:
      sha256 — SHA-256 hex digest of data
      uuid   — generate a random UUID
      rand   — hex string of n random bytes (default 16)

  @thread
    Worker-thread helpers (Node 12+).
    payload: { op, code }
    Operations:
      spawn — new Worker(code, { eval: true })

  @bench
    Micro-benchmarking.
    payload: { fn, runs? }
    Runs fn() for ctx.runs iterations (default 1000).
    Returns: { ms, runs }

  @hot
    Hot-reload trigger.
    payload: { src }
    Re-executes the given source string immediately.

  @wasm
    WebAssembly module loader (async).
    payload: { url, imports? }
    Fetches, compiles, and instantiates a .wasm file.
    Returns the instance's exports object.

  @strict
    Enable strict-mode validation.
    payload: { on? } (default: true)
    When strict, directive handler errors are rethrown
    instead of being silently swallowed.

  @unsafe
    Bypass runtime safety guards.
    payload: any
    Sets runtime._unsafe = true. Emits a console warning.
    Use with caution.

  @sandbox
    Hard-isolate a portion.
    payload: { portion }
    Returns { sandboxed: true, name: portion }.

  @native
    Call into a host-provided native function.
    payload: { fn (function), args? (array) }
    Returns fn(...args).

  @macro
    Define a compile-time macro.
    payload: { name, body }
    Stores body in runtime.macros[name].

  @deprecated
    Emit a deprecation warning.
    payload: { name, message? }
    Logs a [ZETA DEPRECATED] warning to console.

  @experimental
    Log experimental API usage.
    payload: { name? }
    Logs a [ZETA EXPERIMENTAL] warning to console.

      Used for diagnostics and error messages.

    ZetaSafeLayer.auditIR(ir) → violations[]

      objects: { op, pos }.

    r1 $-> <num>:10, <str>:"hi"; // fill slots 0 and 1
    %r1                           // read all slots of r1
    %r1:0                         // read slot 0 of r1
    free r1;                      // zero r1
    free r1, r2, r3;              // zero multiple registers
